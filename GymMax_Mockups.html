1. Diagrama de flujo de navegación entre Wireframes
1.1 Flujo principal (socio)

Flujo: El socio ingresa al login → si sus credenciales son válidas accede al dashboard; si no, puede registrarse. Desde el dashboard puede navegar a sedes, reservar clases y ver sus reservas.

1.2 Flujo principal (administrador)

Flujo: El admin se autentica → el sistema valida rol → accede al dashboard administrativo desde donde gestiona socios, sedes y genera reportes.

4. Modelo de datos (MySQL 8.0) — Diagrama Entidad-Relación
Diagrama ER — GymMax
Script DDL MySQL 8.0 (extracto)
CREATE DATABASE gymmax CHARACTER SET utf8mb4 COLLATE utf8mb4_spanish_ci;
USE gymmax;

CREATE TABLE usuario (
  id_usuario  INT AUTO_INCREMENT PRIMARY KEY,
  correo      VARCHAR(80) UNIQUE NOT NULL,
  password    VARCHAR(255) NOT NULL,
  nombres     VARCHAR(80) NOT NULL,
  apellidos   VARCHAR(80) NOT NULL,
  rol         ENUM('SOCIO', 'ADMIN') DEFAULT 'SOCIO',
  creado_en   TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;

CREATE TABLE sede (
  id_sede        INT AUTO_INCREMENT PRIMARY KEY,
  nombre         VARCHAR(60) NOT NULL,
  direccion      VARCHAR(150),
  distrito       VARCHAR(50),
  hora_apertura  TIME,
  hora_cierre    TIME,
  capacidad      INT DEFAULT 100
) ENGINE=InnoDB;

CREATE TABLE membresia (
  id_membresia  INT AUTO_INCREMENT PRIMARY KEY,
  id_socio      INT NOT NULL,
  id_plan       INT NOT NULL,
  fecha_inicio  DATE,
  fecha_fin     DATE,
  estado        ENUM('ACT','VEN','SUS') DEFAULT 'ACT',
  FOREIGN KEY (id_socio) REFERENCES socio(id_socio),
  FOREIGN KEY (id_plan) REFERENCES plan(id_plan)
) ENGINE=InnoDB;
-- (el script completo incluye socio, plan, clase, reserva, asistencia, pago)
